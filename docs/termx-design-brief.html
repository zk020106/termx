TERMX · UI/UX 设计需求 · v0.2

TermX 设计需求书

个人使用的跨平台 SSH 客户端。它把终端、SFTP、端口转发、主机监控放在同一个工作区里，重点是交互顺手、界面耐看，能长时间使用。

使用场景 个人日常开发、运维（不做团队功能） 平台 Windows / macOS / Linux 桌面端 技术 TypeScript + Electron 或 Tauri（待定） 日期 2026-09-24

01产品概述

目标用户

  • 日常开发：连测试、预发、生产环境部署和排查问题，常改远程配置文件、传文件。
  • 运维场景：手上管理几十台主机，常同时在多台机器上看日志、执行命令。
  • 多台电脑：可能在公司和家里的电脑上都要用，需要能方便地迁移配置。

设计目标

快

3 秒内连上任意主机

打开应用 → Ctrl+K → 输入几个字母 → 回车即连接，全程不用碰鼠标。

稳

不会误操作生产环境

生产主机在标签、终端边框、状态栏上都有明显标识；执行高危操作前要求确认。

顺

一台主机，所有工具都在旁边

终端、文件、转发、监控共用同一个连接，在同一个标签里切换，不用另开窗口，也不用重新登录。

范围说明：不做 RDP、VNC 等远程桌面协议。Telnet、串口、Mosh 优先级较低（P2），只需预留入口。

02参考产品取舍

整体交互以 OxideTerm 为主要参考，同时吸收 Netcatty 在主机管理和视觉上的优点。

主要参考

OxideTerm — 学它的工作区模型

  • 以主机为中心：终端、SFTP、转发、监控都挂在同一个主机节点下，共用一条连接。
  • 命令面板加全局快捷键，所有操作都能通过键盘完成。
  • 断线宽限期重连：网络闪断时保留终端内容，恢复后接着用，vim、top 这类程序不会中断。
  • 分屏最多 4 格，分隔线可拖拽调整。
  • 端口转发自动检测远程正在监听的端口，一键转发到本地。
  • SFTP 传输队列显示进度、剩余时间，支持限速。
辅助参考

Netcatty — 学它的主机库和视觉

  • 主机库三种视图：卡片看总览、列表快速扫、树形看层级。
  • 连接后自动识别系统发行版，显示 Ubuntu、CentOS 等图标。
  • 完整的深色和浅色主题，界面整洁，留白舒服。
  • 终端输出按关键词高亮，规则可以自定义。
  • SFTP 支持拖拽上传下载，内置编辑器可直接改文件。
  • 右键可保存当前屏幕内容。

要避免的问题：Netcatty 的操作层级偏深，很多功能要进设置页或弹窗才能完成。TermX 的常用操作要在当前界面内联完成，不打断正在做的事。

03交互原则

设计评审时用这六条逐项检查。

1. 键盘优先，鼠标可达

所有功能都能通过命令面板或快捷键触发。鼠标操作同样完整，右键菜单要全。

2. 少用模态弹窗

编辑主机、查看详情用右侧抽屉；重命名等小操作用内联编辑。只有确认危险操作和验证主机指纹时才用模态框。

3. 状态始终可见

连接状态、延迟、重连倒计时、传输进度一直显示在标签和状态栏上，不需要用户去找。

4. 渐进披露

新建主机最少只填地址和用户名，其他高级选项折叠起来。首次使用时界面不能出现一整屏的表单。

5. 环境有辨识度

生产、预发、测试、开发各有固定颜色，贯穿主机库、标签、终端边框和状态栏。

6. 可撤销优于确认

删除主机、关闭标签用 Toast 提供“撤销”，不弹确认框。只有删除远程文件这类不可撤销的操作才要求确认。

07关键交互细则

连接状态

连接状态用同一套颜色和图标，出现在标签、主机库列表和状态栏三个位置。

未连接 连接中 已连接 重连中 · 剩 18s 已断开 连接失败

连接流程

双击主机 / 回车→打开新标签→显示分步进度→需要时输入密码或验证码→首次连接确认指纹→进入终端
  • 进度显示在标签内部，不弹窗。连接期间用户可以切到其他标签。
  • 连接失败时，在出错的那一步给出原因和操作按钮：重试、编辑主机、复制错误信息。
  • 输入密码的界面有“记住密码”勾选框，默认不勾选。

断线重连

  • 断线后终端内容保持不变，顶部出现一条横幅：“连接已中断，正在重连（剩 18 秒）”，右侧有立即重连和关闭两个按钮。
  • 宽限期内恢复：横幅消失，终端可以继续使用。
  • 宽限期结束仍未恢复：终端变灰，显示“已断开”覆盖层，按回车即可重新连接。

生产环境防误操作

  • 生产主机的标签有红色色条；终端区域有 2px 红色内描边（可关闭）；状态栏显示 PROD 标记。
  • 粘贴多行内容时，先弹出预览浮层，显示行数和内容。
  • 匹配到高危命令规则时拦截，要求用户确认后再执行。
  • 给生产主机发送广播输入或命令片段时，要单独勾选确认。

分屏

  • 把主机从侧栏拖到终端区，会出现上、下、左、右、中间五个放置区；中间表示在当前格打开，四个方向表示在对应方向新建分屏。
  • 也可以用快捷键或右键菜单分屏，默认打开同一台主机的新会话。
  • 当前焦点格用 1px 强调色描边标出；非焦点格文字稍微调暗（可关闭）。

SFTP 拖拽

  • 从系统文件管理器拖入时，目标目录高亮，并提示“上传到 /home/deploy/app”。
  • 拖到某个子文件夹上停留 600ms，会自动展开这个文件夹。
  • 开始传输后状态栏立即出现进度；遇到同名文件时询问处理方式：覆盖、跳过、重命名，并可勾选“全部应用”。

08视觉要求

主题

  • 以深色为主，浅色要同样完整，另支持跟随系统。
  • 终端配色方案和界面主题分开设置；预置 8 套以上配色，如 One Dark、Dracula、Solarized、Nord。
  • 强调色可以更换，预置 6 个。

字体

  • 界面字体使用系统 UI 字体，中文使用苹方或微软雅黑。
  • 终端默认 JetBrains Mono，支持连字和 Nerd Font 图标。
  • IP、端口、大小、速度等数字一律用等宽数字。

密度与尺寸

  • 提供标准和紧凑两档密度；标准档列表行高 32px，紧凑档 26px。
  • 圆角克制：面板 8px，按钮和输入框 6px，标签 6px。
  • 尽量不用阴影，层级靠背景明暗区分；浮层可以用阴影。

动效

  • 时长 120–200ms，使用缓出曲线。
  • 用于抽屉滑入、标签切换、分屏展开、Toast 出现。
  • 终端区域内不加任何动画；系统开启“减少动态效果”时关闭所有动画。

图标

  • 使用线性图标，风格参考 Lucide，线宽 1.5px。
  • 系统发行版图标使用各自的品牌色，需要准备 15 个左右。
  • 环境标记用文字胶囊（PROD、STG、TEST、DEV），不单独用颜色点区分。

环境色

  • ■ 生产 红　■ 预发 琥珀　■ 测试 绿　■ 开发 灰
  • 环境色和语义色（成功、警告、错误）要能区分开，不能和强调色冲突。
  • 深浅两套主题下都要满足 WCAG AA 对比度。
